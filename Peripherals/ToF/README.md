# VL53L5CX 安装

本机装上随模块附送的黑色前罩后，距离读数出现偏差。装机取下前罩。Blender 默认显示裸板，前罩保存在隐藏集合中。

模块横装，焊盘朝下。先将 SH1.0 四芯线的一端接 HAT，另一端剪去插头，按两端接口定义焊接电源、地、SCL 和 SDA。23 号 v3.11 在六个焊盘下方留了 0.80 mm 深的避让槽。[线材规格](../../BOM/README.md)

固定时让芯片对准脸板前窗，再交替拧紧两个安装耳。两孔中心距 20 mm，板厚实测 1.6 mm，板孔约 Ø3.5 mm。新版支座高 2.5 mm，使用两颗 **M2×4 宽头平尾自攻螺丝**，帽底承压直径约 Ø4.5 mm，直接压板，无垫片。螺杆入柱 2.40 mm，孔底留 0.30 mm。第一版实装使用 M2×5。[安装剖面](../../Docs/Images/tof-camera-mount.png)

芯片前端距脸板外表面约 2.30 mm。前窗内口为 10.8 × 6.0 mm，向外放宽到 12.0 × 7.2 mm。按规格书收发窗口和板孔允许的 0.75 mm 平移量核对，脸板避开光路。新版装机后仍需实测距离和分区方向。[ST 规格书，图 21、24](VL53L5CX-DS13754-Rev5.pdf)
