# STL · 当前打印版本

版本：2026-11-06 v3.6；本次修订 23、27 号，共 29 件，每件数量 1，单位 mm。

按材料 / 颜色分四个文件夹，文件名保留原装配编号。见 [BOM](../../../BOM/README.md) 与 [manifest.json](manifest.json)。

29 件的当前文件均有通过的本地网格检查；修订后的 23、27 号已重新下单，平台复检详情尚未归档。09、22、25、26、28、29、31 沿用已通过平台网格复检的文件，25、26 仍有易变形提示。其他局部薄结构见 [验证状态](../../../Docs/VALIDATION.md)。

23 号相机安装柱与 PCB 绕光轴旋转 90°，柱高为 6.3 mm，相机后移 2 mm，排线接口朝远离 ToF 的一侧；画面需在软件中转回正向。ToF 横装，安装台阶和模块旋转 180° 后上移 2 mm，感光中心与摄像头等高，焊盘排朝下。ToF 两个盲孔孔底从约 0.3 mm 加厚至 1.3 mm，孔深约 3 mm；螺丝伸入打印件的长度宜不超过 2.5 mm，按实际板厚选择螺丝。相机使用 M2×4 自攻螺丝时，穿过约 1.6 mm PCB 后伸入约 2.4 mm。实物装配和成像仍待验证。

27 号眼圈正面减薄 2 mm，总厚度为 6 mm。按参考玻璃模型，固定头部对平整地面的最小几何余量约 0.65 mm，保护来自上壳与眼圈共同支撑；这不是跌落测试结论。上壳会进入保守的 160° 视场包络，实拍时需确认画面边缘遮挡。
