## 打印

| 材料与颜色 | 数量 | 零件编号 |
| --- | ---: | --- |
| 9000HE 白色 | 8 | 03、04、09、10、25、28、29、32 |

| Grey 灰色 | 16 | 05–08、13–22、24、26 |
| TPU 95A 黑色 | 2 | 01、02 |

共 29 件，每件 1 个，文件单位 mm。11、12、30 号采用金属成品。STL 用于当前打印；STEP 为同一批零件的 CAD 参考文件。

25、26 号为大跨度薄壳，保留易变形提示，壁厚按现有方案。打印公差及材料强度待实物验证。

## Blender

文件以 Blender 5.2.3 LTS 保存，默认对象模式，每个零件可单独选择。Outliner 按打印件、舵机、板卡、外设、轴承和金属件分类；“电路与外设 · 查看”视图层用于查看内部装配。

两份文件几何相同，仅配色不同，均包含 29 件打印件、15 个舵机、14 个轴承及完整板卡和外设。电池为铁头 TNP-F550-GN 参考模型，无外部贴图或链接库依赖。

场景采用米制并显示为毫米；整机中的板卡、舵机和外设不属于打印件。打印请使用 `Print/STL` 下的单件文件。
